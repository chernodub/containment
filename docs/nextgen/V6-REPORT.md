# V6 — texture-authored abilities

Branch: `t3/textured-ability-vfx`. Frozen application revision: `dd4aa2e2c4ba44de8f9fea133e2844c6f4507b43`. Delivery HEAD is reported in the final handoff. No push or PR. Work is confined to this worktree and the assigned ability/assets/credits/tests/additive-capture scope. Simulation, world/props/lighting, actors, camera and UI source are unchanged.

## Result and acceptance scope

The effect class changes from analytic flame/gas silhouettes to authored flipbooks and offline texture masks. Flashfire uses layered short turbulent plumes plus an authored explosion beat; Napalm uses edge fire, tall vents and a smoke column; Afterburn stays low; Meltdown has tall rear flame, low armor-flank fire, embers and burning footprints. Overclock adds textured armor/muzzle arcs, bright human echoes, moving-enemy scan impressions and trails separated behind hostile projectile heads. Bulwark has two emitters and a directional hex/scan field with native shot-crossing ripples. Glacier has a grounded ridge, unequal textured crystal teeth and frost spread. Nova, Trail, Slam, Railbreaker, Ram, Static Step, Overload and Pylon use the shared textured vapor, sparks, impact stars, frost and shockwave presentation while retaining native hit boundaries and Arc chain endpoints.

The existing weapon/explosion pipeline already uses CC0 Explosion01 and WispySmoke02; those original assets and their notices are retained unchanged. Simple weapon tracer/impact cores remain analytic. No world/actor kits were imported in this stream.

This is an implementation handoff, not an independent art-director pass. Whiteout is still the weakest ultimate: spherical billows and driven snow replace flat streaks, but it remains a band of stylized cloud masses rather than continuous simulated weather. Frozen crowds still compress anatomy. Glacier's texture approximates internal refraction and its repeated primary teeth remain visible. Overclock echoes are authored generic silhouettes, not captured animated suit poses.

## Runtime and budgets

Eight existing instance batches, one shared atlas, one retained friendly boundary batch and the existing lightning pool. No new particle render pass or dynamic shader variant; no per-effect material/geometry creation. Fire/smoke interpolate frames on the presentation clock with stable source-independent seeds; paused/reduced-motion clocks stay fixed. Vapor/light face the full camera basis; fire remains upright, flow strips retain world endpoints, fields stay vertical and decals stay on the deck. Smoke/ice use premultiplied output, light uses additive blending, gases have no ink; solid constructs keep thin inked edges.

High projected rectangle-estimate caps: fire .30 / smoke .18 / billboard decals .28 of the viewport accumulated across a batch; Low .16/.10/.14. These include overlapping rectangles rather than measuring opaque pixel coverage. Fixed pools, per-instance priority, alpha-edge softness, floor-intersection fade, Low reductions and idempotent disposal remain. Flat/ribbon-like layers and pressure fronts submit both faces once, removing redundant transparent submissions. Exact catalog/snapshot boundaries, hostile overlay order and local actor/danger yielding are retained. No half-resolution particle buffer was required by the measured cohort.

**Integration requests outside ownership:**

1. `AbilityVisuals.prepare()` exposes atlas decode readiness. The current owned-module fallback starts on the first non-menu game update and never requests the atlas on title. The room/application owner should await that promise and call `renderer.initTexture(visuals.kit.atlas.texture)` before combat readiness/material warmup to give a strict first-room decode/upload guarantee, including first Continue. These calls belong in the first non-menu room hold, not initial title preparation. This hook is not yet wired into the external room-loading hold.
2. `AbilityVisuals.setSoftDepth(detachedOpaqueDepth, near, far, perspective)` provides scene-intersection fading without shader variants. It must receive a detached opaque-depth copy, never the scene depth currently being rendered. No such copy/split exists in this ownership scope. Shipped effects have soft texture silhouettes and deck fading; **true scene-depth soft particles remain unbound**. The active scene attachment cannot safely be sampled during its own render.
