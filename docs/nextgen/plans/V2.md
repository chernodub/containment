# V2 ability presentation plan

Own `src/render/abilities/**`, ability tests, additive capture scenarios and surgical DepthRenderer hooks. Visual only; no audio, UI, simulation, smoke or unrelated world edits.

Shared framework first: authoritative catalog/event shape resolver, fixed instanced particle and solid batches, short ring/beam/decal receipts, G1 telegraph/ribbon/zone composition, exact snapshot footprints, element palette, tier/options handling and services for bounded LightPool/distortion/CameraRig. All resources constructed before material registration; clear on room change, idempotent disposal, no render-driven gameplay.

Then disjoint rig modules (Breacher, Cryo, Pyro, Arc) and system feedback/poses/struck states. Each composes shared primitives and reads immutable snapshots. Lead owns integration and capture helpers. Native child agents are explicitly authorized by the task; no child checkout or recursive delegation.

Review: baseline sixteen abilities plus per-rig combat; three full critique/fix galleries. Add six-phase and three-environment fixtures plus 25-enemy High/Low kit stress. Preserve existing capture IDs/assertions. Final per-ability sheets and four kit sheets under artifacts/nextgen/v2-final. Record actual timing/draw/light/instance values and distinguish frozen capture from live timing.

Gates: npm run verify (known Blender limitation), standalone build, model preview, room evidence, desktop smoke and authored smoke. New structural tests cover exact dimensions including augmented receipt shapes, bounded pools, tier switches, pause/clear/dispose and routing. Existing desktop/gameplay assertions remain.

Risks: shader inventory must retain topology including instanceColor; event receipts coalesce at 250ms so persistent visuals follow snapshots; effect transparency must preserve hostile red and actor silhouettes; no new shared renderer capability unless strictly additive.
