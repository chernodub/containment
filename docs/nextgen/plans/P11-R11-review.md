## Atlas accounting for the incident pass

There are now **14 authored source packs: four E9 + ten P11**, including `p11-incidents`. Each inspected manifest records one 512×512 tangent normal atlas and `normalAtlas.estimatedRGBA8MipBytes = 1,398,101`. Total distinct authored normal-atlas storage bound: **19,573,414 bytes (~18.667 MiB)**. This is a calculated RGBA8+mip bound, not measured GPU-process memory. Embedded GLB image and external rebuild PNG are one runtime image, not two. AO/curvature remain vertex data.

The incident pack contains six models: abandoned-winch-repair, failed-shield-leaves, strained-containment-diaphragm, consuming-workstation-mantle, brood-stronghold-wall and failed-relay-patch. It adds one atlas (~1.333 MiB) to source requirements for Service Shaft, Shielding Gate, Containment Annulus, Infested Workshop, Swarm Junction and Relay Racks. Latest model counts, file bytes and final normal pixels must be read after the pending rebuild. Low omits designated secondary geometry but retains warm buffers/materials/textures; no atlas-memory reduction is claimed. Source caches may retain packs from earlier rooms.
