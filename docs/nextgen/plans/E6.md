Four standard rounds were followed by an independent all20 native/480 review. The raw primary ad15 gallery is preserved as `e6-primary`; rejected cabin loss and story/landmark clutter are retained there. The corrected application `207d496` requires all four major cabin forms before retiring the prior source, uses actual authored-triangle checks to resolve conservative bed/table box false positives, and adds a full post-kit119-ray story-screen regression in three rooms. Only room construction and existing idle prepare-ahead request them; owner readiness is included before shader preparation. Five source palette roles plus organic/conduit finishes normalize through existing room materials, local-light/banded shading and geometry registration. New room meshes are static and merged into at most eight draws, with the original17k kit triangle admission cap (superseded by the density revision below). Full `verify` is retained even though the documented missing Blender prerequisite may stop the Python stages. Browser gates, capture and native benchmarks are then run serially. No user process or simulator is stopped.
