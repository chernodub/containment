# D11 implementation plan

Use one deterministic difficulty descriptor, preserving Standard multipliers. Persist mode in checkpoints with Standard defaults, and keep selection/hints preferences in UI storage. Integrate contextual hints with snapshot observations and public actions. Reuse room damage telemetry for death feedback. Bot entrypoints forward the mode without changing controller policy.

Disjoint implementation streams own simulation/checkpoints, UI, and bot CLI/balance. Integration owns build, native captures/campaigns and final report. Limit simulation concurrency to three and serialize browsers. Principal risks are changed Standard opening balance, hint retirement observation, and cohort targets requiring several tuning passes.
