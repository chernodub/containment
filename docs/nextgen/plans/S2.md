# S2 audio implementation plan

Implement the frozen GameAudioDirector on AudioSystem; preserve every legacy public entry point. No simulation/UI/render edits. Original deterministic PCM recipes supplement the licensed local samples; no dependencies or downloaded audio.

1. Land a shared mix engine and synthesis toolkit: seven buses, effects/music controls, filter/duck/reverb/limiter, priority admission with bounded fading voices, safe envelopes and seeded layered PCM. Separate pure authoring recipes from playback.
2. Delegate disjoint recipe families after that foundation: abilities; weapons/impacts/enemies; environments/UI. Integrate routing, sample layers, keyed loop lifecycle and reactive state personally.
3. Build a dev-only audition entry and Chromium OfflineAudioContext evidence runner. Measure every recipe, actual layered sample weapons, bus stems and limited master during a deterministic dense fight. Export WAV and waveform/spectrogram PNGs. Two visual critique/fix rounds.
4. Add routing/flood/lifecycle/resource tests and numerical signal assertions. Run engineering gates plus requested verify (its known Blender prerequisite may fail; report it without changing assertions). Small commits, no push/PR/merge.

Modules: synthesis.ts (pure PCM API), MixEngine.ts (Web Audio resources), *Cues.ts (owned recipe families), AudioSystem.ts (director and compatibility), tests/Audio*.test.ts, scripts/nextgen/audio-* (audition/evidence), artifacts/nextgen/s2-audio (generated review evidence).

Risks: dense action masks transients; mitigate family loudness budgets, reserved important voices and ducking. Cached buffers can hitch on first use; prewarm one recipe per idle task and measure cold/init costs. Lingering entities may overlap; key loops by ability + entity ID, bounded globally, with event lifetimes as a fallback. Existing tests pin gain creation order/private implementation; replace those assertions only with equivalent real graph/volume guarantees where necessary. UI integration is read-only and remains a report hook.
