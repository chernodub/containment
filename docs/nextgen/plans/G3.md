# G3 render pipeline plan

Use a second HDR scene attachment for geometry normals/identity, avoiding an additional scene traversal and preserving P1 draw headroom. Central material patches retain prior hooks, skinning, dissolve and shader cache families. Actor identity is a uniform shared by that actor's materials, so overlapping rigs stay distinct without shader variants. Non-surface effects are excluded from contour classification. AO reads the same geometry attachment.

Ink is merged into the existing composite, with stable pixel-space taps and depth/normal rejection. High uses full ink; Low uses a compact silhouette composite. Surface response is patched centrally with shared ramp/detail uniforms. Keep selected-configuration warmup and actual warm draws.

Profile opt-in asynchronous disjoint GPU queries per stage. Evaluate MSAA removal with post AA, fullscreen tap reduction and adaptive 0.7–1.0 internal scale. Preserve native desktop and all existing resource/preparation/program guards. Keep one capture/benchmark browser active. Capture three OFF/ON review rounds before final all-room rollout; retain failures and honest timing misses.

Owned modules: post, material shader plumbing, graphicsOptions, FrameBudget, nextgen bench/capture scripts, surgical DepthRenderer hooks. No UI/game/ability/content edits. Main risks: MRT compatibility with custom effects, actor material lifetime, first-frame shader variants, output-space AA and contested-host timing.
