## Shared seams and constraints

All room additions happen before lighting discovery, mood application and material registration. New material families are retained by `MaterialWarmup.register(world)` and included in actual High/Low warm draws; dynamic actor/pickup topology must exist during initial preparation. Title uses the existing menu flag and restores native game camera on exit. Low allocates no post resources. No ability, UI, audio, game, collision, navigation or smoke files are edited.

Use deterministic seed hashing, merged/instanced detail and bounded shared materials. Do not invent objects on traversable ground. Keep desktop framing, pointer, resizing, recovery, authored-room and all safety assertions. New systems need lifecycle/budget/determinism tests. Add no dependencies/assets without provenance.
