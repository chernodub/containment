Title uses the existing menu flag and restores native game camera on exit. Low allocates no post resources. No ability, UI, audio, game, collision, navigation or smoke files are edited.

Use deterministic seed hashing, merged/instanced detail and bounded shared materials. Do not invent objects on traversable ground. Keep desktop framing, pointer, resizing, recovery, authored-room and all safety assertions. New systems need lifecycle/budget/determinism tests. Add no dependencies/assets without provenance.
