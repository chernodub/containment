# Containment V6 compact effect atlas

One 2048×2048 RGBA PNG, 16×16 padded tiles, mipmapped at runtime.

Derived Unity Labs and Kenney data: CC0 1.0, see ../unity-labs-v6 and ../kenney-particle-v6. Original offline-generated bolt/mist/frost/crystal/energy/decal masks: Containment contributors, repository MIT. Generator: tools/assets/vfx/build_atlas.py (Pillow + NumPy in an isolated build environment; no runtime dependency).

Source and output SHA-256, frame addresses and byte size are in atlas.json.
