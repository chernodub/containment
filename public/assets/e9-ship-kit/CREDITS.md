# Original Containment ship interiors

Original2026 Containment overhaul art, authored with Blender through the
reproducible scripts in `tools/assets/e9-ship-kit/`. MIT, as the repository; full
license text is included in each pack directory. No third-party source meshes,
bitmap textures or new downloads were used in these four packs.

Runtime GLBs: `structure/structure.glb`, `security/security.glb`,
`clinical/clinical.glb`, `industrial/kit.glb`. Each adjacent manifest records the
exact export hash, material and model inventory, dimensions and rebuild command.

Retained native landmarks and legacy CC0 fallbacks continue to use their existing
credits and licenses under `public/assets/`; those notices remain authoritative
for those separately owned models and textures.
