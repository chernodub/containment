# M10 motion adaptations

Blender-authored animation curves, temporary IK controls and export tooling were
created for Containment in November 2026. The generating Python/JavaScript source
uses the repository MIT license. Animation-only GLBs retain the existing model
skeletons and are distributed under CC BY-SA 4.0, consistently with the adapted
models. They contain no marine, weapon or creature mesh or texture.

Retained skeleton sources and contributors:

- Marine: Unvanquished human male/medium armor; Angel “Angelo” Bedolla,
  Jan “Stannum” van der Weg, Viech and animation contributors.
- Crawler: Dretch; Greg “Gregstein / Gregorein” Bak, Daniel “DandoomBuggy” McCarthy, gavlig.
- Stalker: Mantis/Basilisk; Sewer Hrehorowicz, Sergio “Cupside” Anes Alcolea, Stannum, gavlig.
